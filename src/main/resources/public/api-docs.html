Expected status codes

200 OK · successful GET / PUT / PATCH
201 Created · successful POST
204 No Content · successful DELETE / OPTIONS
400 Bad Request · invalid JSON, fields or values
404 Not Found · resource does not exist
405 Method Not Allowed · unsupported method
409 Conflict · business/data conflict where applicable
415 Unsupported Media Type · write request without application/json

Useful headers

Location · Allow · X-Total-Count · X-Page · X-Page-Size · Content-Type
